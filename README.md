# QuickADBackup

Android端末のストレージをUSBデバッグ機能でPCへ高速でバックアップできるWindows向けのツールです。差分バックアップや並列処理に対応しています。

## 準備

端末側の設定だけです。PC側に入れるものはありません。

1. 「設定 > デバイス情報」を開き、「ビルド番号」を7回連続でタップします。開発者向けオプションが有効になります。
2. 「設定 > システム > 開発者向けオプション」を開き、「USBデバッグ」をオンにします。
3. USBケーブルでPCと接続します。データ転送に対応したケーブルが必要です。充電専用ケーブルでは通信できません。
4. 画面ロックを解除しておきます。次の手順で表示される許可のダイアログは、ロック中は操作できません。

項目の名前や階層はメーカーによって異なります。見つからない場合は設定内を「ビルド番号」「USBデバッグ」で検索してください。

## 使い方

`quickadbackup-gui.exe` を起動すると、保存先を選んで実行するウィンドウが開きます。

1. 上部の「デバイス」に接続した端末の名前が表示されます。初回接続時は端末側に「USBデバッグを許可しますか?」が表示されるので「許可」を押してください。「このパソコンからのUSBデバッグを常に許可する」にチェックを入れると、次回以降は表示されません。
2. 「接続していません」「未接続」と表示されたままなら、端末の画面ロックを解除して「再接続」を押します。
3. 「バックアップ先」の「参照...」でPC側の保存先フォルダを選びます。
4. 「スキャン (差分を確認)」を押すと、転送されるファイルを実行前に確認できます。
5. 「バックアップ」を押すと転送が始まります。進捗とログはウィンドウ下部に表示されます。
6. 「検証」を押すと、保存したファイルを端末と照合します。

認証にはadbと同じ鍵（`%USERPROFILE%\.android\adbkey`）を使います。すでにadbで許可済みの端末なら、初回の確認は表示されません。

`quickadbackup.exe` はコマンドラインから実行します。スクリプトや定期実行向けです。

```
quickadbackup probe                    # 端末の対応状況を確認
quickadbackup sync -dest D:\Backup     # 新規・変更分をコピー
quickadbackup verify -dest D:\Backup   # バックアップを端末と照合
```

| フラグ | 意味 |
| --- | --- |
| `-dest DIR` | PC側の保存先（必須） |
| `-root DIR` | 端末側の対象フォルダ（既定 `/storage/emulated/0`） |
| `-exclude LIST` | root からの相対パスをカンマ区切りで除外 |
| `-workers N` | 並列転送ストリーム数（既定 8） |
| `-dry-run` | 実行内容の表示のみ |
| `-sample N` | `verify` 用。無作為に N 件を照合（`0` で全件） |
| `-device FRAG` | 複数台接続時の選択 |

`Android/data` と `Android/obb` は既定で除外します。

## 速度

Pixel 7 / Android 16 / USB 3、`Pictures` 7,204ファイル・1.1GiB:

| | adb経由 | このツール |
| --- | --- | --- |
| 初回バックアップ | 49.3秒 | 18.0秒 |
| 2回目（変更なし） | 1.8秒 | 1.8秒 |
| 転送速度 | 15.3MiB/s | 101.7MiB/s |

## ビルド

```
go build -o quickadbackup.exe .
go build -ldflags "-H=windowsgui" -o quickadbackup-gui.exe ./cmd/gui
```

`cmd/gui/rsrc.syso` は `app.manifest` を埋め込んだもので、GUIの起動に必要です。
